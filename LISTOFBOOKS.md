# Книги и справочники для порта MINIX 1 на i386

Подобрано под конкретные задачи проекта — что читать для какого куска кода.

## Главная

### Tanenbaum, Woodhull — «Operating Systems: Design and Implementation», 1-е изд. (1987)
**Книга, по которой написан именно этот код.** Приложение содержит полный
листинг MINIX 1, а основной текст построчно объясняет `kernel/proc.c`,
`mpx88.s`, `mm/`, `fs/` — ровно те файлы, которые мы портируем.
- Читать вместе с кодом: главы 2–4 ≈ kernel+tasks, глава 5 ≈ MM,
  глава 6 ≈ FS.
- Важно брать **первое издание** — 2-е (1997) описывает MINIX 2.0
  (POSIX, другой код), 3-е (2006) — MINIX 3 с драйверами в юзерспейсе.
- 3-е издание полезно только для сравнения «куда эволюционировала идея».

### Bach — «The Design of the UNIX Operating System» (1986)
MINIX FS — упрощённая копия Unix v7 FS. Бах объясняет именно ту модель,
которую воспроизводят `fs/cache.c` (буферный кэш), `fs/inode.c`,
`fs/path.c` (namei-разбор путей), `fs/super.c`. Когда логика оригинала
непонятна — ответ обычно здесь.

## Архитектура x86 / protected mode

### Intel SDM, Volume 3A — «System Programming Guide»
Авторитетная справка по всему, что делает порт: GDT/IDT-дескрипторы,
гейты прерываний, PIC-векторы, TSS, ring-уровни, CR0/PE. Не читается
целиком — используется как справочник при написании IDT и `mpx_i386.s`.

### Crawford, Gelsinger — «Programming the 80386» (1987)
Книга от архитекторов самого i386 — ровесница MINIX. Protected mode
описан в том виде, в каком мы его используем (flat-сегменты, гейты,
far call/iret) без современных наслоений (PAE, long mode, APIC).
Хорошо ложится на наш минимальный срез.

### OSDev Wiki — wiki.osdev.org (не книга, но обязательный справочник)
Конкретные рецепты: ремап 8259 PIC, программирование PIT 8253 (порты
0x40/0x43, `IBM_FREQ`), UART 16550 (COM1), PS/2 клавиатура, VGA text mode
(0xB8000), boot sector + int 13h. Закрывает 90% «как это делается на железе».

## Unix-семантика userspace

### Stevens, Rago — «Advanced Programming in the UNIX Environment» (APUE)
Для стороны `lib/`+`commands/`: точная семантика fork/exec/wait/exit,
дескрипторов, stdio-буферизации — то, что должен воспроизводить наш
`libinit.a`→libc. Нужна, когда дойдём до shell и команд.

### Arpaci-Dusseau — «Operating Systems: Three Easy Pieces» (OSTEP, бесплатная)
ostep.org. Современное объяснение процессов, планировки, VM, FS-журналов.
Не про MINIX и не про наш код, но лучший источник «почему устроено так» —
полезна как общий фон, если книга Таненбаума кажется слишком сухой.

## Ближайший аналог проекта

### Cox, Kaashoek, Morris — «xv6: a simple, Unix-like teaching operating system» (book + исходники)
xv6 — это Unix v6, переписанный на i386 (а позже RISC-V) для обучения:
тот же масштаб (~10K строк), тот же вопрос «как уложить Unix-модель на
32-битный x86». Их `trapasm.S`, `proc.c`, `sysfile.c` — готовые ответы
на наши задачи: структура IDT/trapframe, контекст-свитч на `struct context`,
загрузка ELF в `exec.c`. **Самый полезный референс после книги Таненбаума** —
смотреть, как они решали именно x86-специфичные части.
pdos.csail.mit.edu/6.828/ (исходники и commentary свободно доступны).

## Опционально / по вкусу

- **Tanenbaum — «Modern Operating Systems»** — общая теория ОС; фон, не рецепт.
- **van Gilluwe — «The Undocumented PC»** — глубокие детали PC-железа
  (PIC, PIT, порты, VGA-регистры); если захочется настоящий floppy/ATA-драйвер.
- **Bovet, Cesati — «Understanding the Linux Kernel»** — как те же идеи
  (прерывания, schedule, buffer cache) выглядят во взрослом ядре на x86;
  полезно для проверки «а не упустил ли я что-то».
